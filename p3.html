Patterning 3 3.2

July 25, 2025
  • Auto-Create Kits New AUTO-CREATE KITS option in the Project Kits tab. When enabled, a new drum kit is automatically created for each new pattern. Ideal for workflows where each pattern needs unique sounds or settings.
  • Pattern Reset Added per-pattern reset option. When enabled, the pattern resets to the beginning each time it is triggered. Show this feature by holding ALT in the Pattern Select tab. Use APPLY TO ALL to quickly apply across all patterns.
  • Project Drum Kit Images Project drum kits now display randomly generated images for easier visual identification. Images are created by cropping a random section of the kit’s official art.
  • Timeline Reordering You can now drag to re-order Timelines in the Timelines view. Note: This works only when the clock is stopped.
  • Export UI Improvements Exporting now provides clearer platform-specific options:
  • On macOS Standalone: Always prompts for save location. Standalone version includes “Show in Finder” after export.
  • On iOS: Includes “Share” and “Show in Files” options.
  • MIDI Control Enhancements Added MIDI mapping for “Clear Pattern” Fixed broken “Timeline Enabled” MIDI control
  • News & Tutorials UI Improved sorting and layout for News & Tutorials items for easier browsing.
  • Bug Fixes & Stability Fixed Logic keystroke conflict when plugin is focused Fixed layout issue for 11-inch iPads in AU Fixed crash on beta versions of iPadOS 26 and macOS 26 Fixed sample gain not being restored after editing Future-proofing UI for upcoming OS changes Fixed bug with accessing drag & drop samples between launches on macOS Audiounit. Samples imported this way will now be copied to an "Imported Samples" folder.

Patterning 3 3.1

April 16, 2025

Patterning 3.1 is a major, free update with loads of new features.

  • macOS Patterning 3.1 now runs on Apple Silicon Macs as both a standalone app and AUv3 plugin, working inside hosts like Ableton Live and Logic. AUv3 includes support for multi-channel audio and MIDI output.
  • AU Parameter Support Automate Patterning from your DAW using AU parameters.
  • MIDI File Export Generate MIDI files from your patterns. Drag and drop from the MIDI settings tab to export a single MIDI track, or use the Export Audio & MIDI menu to generate full patterns.
  • Built-in Tutorials Learn more about Patterning from inside the app. Tutorial videos and articles are being added regularly.
  • New Project Dialog Set your project name, tempo, and time signature before creating a new project.
  • Drum Kit Template Make your favorite drum kit the default when creating new projects.
  • Drag and Drop Drag and drop support for quick sample loading. Drag exported MIDI and audio files from Patterning directly to your DAW for additional editing.
  • Updated Audio & MIDI Export Options Choose your export location (macOS), view exported files, and drag them directly to your DAW or another Finder location.
  • Rename Tracks Double-tap on the track selector to rename a track.
  • UI Enhancements Improved access to MUTE/SOLO in the sample editor; more visible track names when in ALT mode.
  • Other Updates Support for additional sample rates and various bug fixes.
